# MOBIUS.TILES

MOBIUS.TILES was Elfege Systems' self-hosted, real-time control surface for multi-hub smart-home
operations. It explored fast local control, durable event history, device normalization, and
privacy-first operation without making a household dependent on a cloud dashboard.

The standalone TILES application is now retired. Its strongest ideas and lessons are being absorbed
into the broader MOBIUS.HOME platform. The implementation remains private and is no longer distributed
through this public repository.
